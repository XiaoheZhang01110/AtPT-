# 环形线路车辆轨迹源数据

## 数据范围

- 策略：NH、FH、BH、HH、SH、MAPPO、改进MAPPO。
- 每种策略包含6辆公交车。
- 仿真时段：0--28 800 s。
- 随机种子：1。
- 站点数：12。
- 发车间隔：360 s。

## 目录结构

每个策略文件夹包含：

- `bus_0.csv`--`bus_5.csv`：逐车、逐秒轨迹数据。
- `manifest.json`：策略参数、模型类型、车辆数、记录数和质量检查结果。

## CSV字段

| 字段 | 含义 |
|---|---|
| `time_step` | 仿真时间步，单位为s |
| `loc_rad` | 环形线路上的车辆位置，单位为rad |
| `station_position` | 用站点序号表达的连续车辆位置 |
| `is_stopped` | 该时间步是否处于站点停车状态 |
| `stop_id` | 停车站点编号；运行状态为-1 |

## 复现说明

数据由原始仿真代码和保留的模型权重重新生成。规则策略对应控制参数
0、1、3、4和5；MAPPO及改进MAPPO对应控制参数2。原工程的仿真终止条件
现为3 h，而硕士论文轨迹图横轴为8 h，因此本次复现将终止时间显式设为
28 800 s。所有轨迹均检查了非环线回绕导致的位置递减，结果为0。
