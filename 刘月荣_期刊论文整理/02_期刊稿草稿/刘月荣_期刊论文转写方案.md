## 一句话论证

In bus holding control for unstable urban transit operations, this study proposes an event-graph-enhanced MAPPO framework that uses graph attention to model asynchronous inter-vehicle interactions, supported by controlled ring-route simulations and a Chengdu T34 route case study, with the current evidence bounded to single-route holding control under simulated passenger demand and homogeneous vehicle assumptions.

## 推荐题目

1. Event-graph-enhanced multi-agent reinforcement learning for bus holding control under asynchronous arrivals
2. Graph-attention MAPPO for dynamic bus holding control in bunching-prone transit operations
3. Dynamic bus holding control with event-graph attention and multi-agent proximal policy optimization

当前最稳妥题目：`Event-graph-enhanced multi-agent reinforcement learning for bus holding control under asynchronous arrivals`

原因：既包含核心方法 event graph / multi-agent reinforcement learning，也包含应用对象 bus holding control 和技术挑战 asynchronous arrivals，避免过度承诺“最优”“实时部署”等尚未完全由证据支撑的说法。

## 建议期刊稿结构

### 1. Introduction

段落任务：

1. 城市公交串车导致车头时距失稳、等待增加和资源利用不均。
2. 传统驻站控制依赖局部或规则化车头时距信息，难以在动态和异步到站环境中协同决策。
3. 强化学习适合动态控制，但常规 MAPPO 对公交异步到站事件之间的相互影响表达不足。
4. 本文提出 event-graph-enhanced MAPPO，并在理想环线和成都 T34 路场景验证。

需避免：

- 不要把绪论写成“大数据、人工智能快速发展”的泛背景。
- 不要把国内外研究现状逐篇罗列。
- 不要使用“首次”“创新性”这类没有文献边界支撑的措辞。

### 2. Method

建议小节：

1. Problem formulation
2. Bus operation and holding-control environment
3. Markov game formulation
4. Event graph construction for asynchronous arrivals
5. GAT-enhanced MAPPO architecture
6. State, action and reward design
7. Training and implementation details

方法主线：

`task formulation -> bus operation simulation -> asynchronous event graph -> GAT policy enhancement -> reward and training`

### 3. Experiments

建议小节：

1. Experimental settings
2. Baseline policies and metrics
3. Controlled ring-route simulation
4. Chengdu T34 case study
5. Comparison with rule-based, optimization-based and MAPPO baselines
6. Ablation or sensitivity analysis

建议主文重点放在成都 T34 路场景；环线场景作为 controlled benchmark，用来说明模型在简化条件下可训练、可收敛、优于基准。若版面有限，环线结果可放补充材料。

### 4. Results

结果叙述顺序：

1. 模型训练收敛。
2. 车辆轨迹显示 bus bunching 得到缓解。
3. 载客离散度显示车辆资源利用更均衡。
4. T34 场景量化结果显示 enhanced MAPPO 在 AWT、AHT、ATT、AOD 上均优于 MAPPO 和传统基准。
5. 相比原始 MAPPO，重点报告 AWT -7.84%、AHT -27.78%、ATT -2.94%、AOD -11.11%。

### 5. Discussion

需要回答：

1. 为什么事件图 + GAT 对异步到站有效？
2. 为什么传统 HH/FH/BH 会降低等待但增加旅行时间或驻站时间？
3. 为什么 enhanced MAPPO 的 AHT 更低，同时 AWT 和 ATT 也更低？
4. 当前边界在哪里：单线路、同质车辆、乘客不放弃等待、仿真验证而非线上部署。

### 6. Conclusion

结论只保留一段或两段：

- 提出方法
- 总结最强证据
- 点出应用意义
- 承认边界
