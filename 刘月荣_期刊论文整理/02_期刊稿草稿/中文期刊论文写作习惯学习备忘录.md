## 中文期刊论文的常见结构

中文交通类算法/模型论文通常采用以下结构：

1. 引言
2. 问题描述与模型假设
3. 模型构建
4. 算法设计
5. 算例分析或实例验证
6. 结论

对于刘月荣这篇，建议压缩为：

1. 引言
2. 公交动态驻站控制问题描述
3. 基于事件图注意力的改进 MAPPO 驻站控制模型
4. 算例仿真与实例分析
5. 结论

不建议保留硕士论文式章节：

- 强化学习基础理论及相关知识
- 大段政策背景
- 大段国内外研究逐篇综述
- Python 类定义和代码实现细节
- 过多中间推导和重复图表

## 摘要写法

中文交通期刊摘要常见模式：

`研究目的/问题 -> 方法构建 -> 数据或实验设置 -> 结果量化 -> 结论意义`

推荐句式：

- 为缓解城市公交运行中的串车现象，提出……
- 针对传统驻站控制策略难以适应车辆异步到站和客流随机波动的问题，构建……
- 将公交车辆视为智能体，以……为状态变量，以……为控制动作，设计……
- 采用……线路数据进行实例验证，并与……策略进行对比。
- 结果表明：与……相比，所提模型在……指标上分别降低……

摘要中必须有量化结果，不宜只写“效果显著”“验证了有效性”。

## 引言写法

中文期刊引言通常分为 4 个功能段。

第一段：问题背景。

- 从公交服务可靠性、串车、车头时距失稳切入。
- 不宜从“大数据、人工智能快速发展”泛泛开头。

第二段：既有方法。

- 传统方法：车头时距控制、时刻表控制、驻站控制、限流、跳站、速度控制等。
- 强化学习方法：可处理动态随机环境，但已有方法对异步到站和多车协同表达不足。

第三段：研究不足。

- 传统规则或优化模型依赖局部车头时距，难以刻画多车动态交互。
- 普通多智能体强化学习通常假设智能体同步决策，但公交驻站决策发生在车辆异步到站事件上。
- 对乘客等待成本和运行稳定性的协同权衡仍需进一步加强。

第四段：本文工作。

- 建立公交驻站控制的多智能体强化学习模型。
- 构建事件图描述公交到站事件之间的异步关联。
- 在 MAPPO 中引入图注意力网络，学习相邻车辆事件对当前车辆决策的影响。
- 通过算例和成都 T34 路实例验证模型性能。

## 方法部分写法

中文交通类期刊的方法部分通常强调“建模闭环”，即：

1. 系统对象
2. 变量定义
3. 状态转移或约束
4. 优化目标或奖励函数
5. 算法流程

刘月荣这篇应避免把方法写成强化学习教材。应直接写：

- 公交线路与车辆运行过程
- 车辆到离站时间
- 乘客到达与上下车过程
- 状态空间
- 动作空间
- 奖励函数
- 事件图构建
- 改进 MAPPO 算法流程

中文句式要偏“工程建模”：

- 设线路包含 `m` 个站点和 `n` 辆公交车。
- 车辆 `b_i` 到达站点 `s_j` 后，依次完成上下客服务和驻站控制决策。
- 以车辆前向车头时距、后向车头时距和车内乘客数构成状态空间。
- 将驻站时长归一化为连续动作变量。
- 构建兼顾车头时距稳定性和乘客等待成本的奖励函数。

## 算法部分写法

算法部分要讲清楚“为什么改”和“怎么改”，不能只堆公式。

建议顺序：

1. 说明 MAPPO 适用于多智能体连续控制。
2. 指出公交驻站控制的异步性：车辆不是同时到站，也不是同时决策。
3. 构建事件图：节点为车辆到站事件，边表示时间窗内相邻车辆到站事件对当前事件的影响。
4. 使用 GAT 学习邻居事件权重。
5. 将事件图聚合信息输入策略网络，辅助生成驻站动作。
6. 给出训练流程或伪代码。

建议表达：

- “与同步决策场景不同，公交驻站控制仅在车辆到达站点时触发，具有显著事件驱动特征。”
- “为刻画异步到站事件间的局部关联，本文构建事件图网络。”
- “图注意力机制能够根据邻接事件的重要程度自适应分配权重，从而增强智能体对相邻车辆影响的感知能力。”

## 算例与实例分析写法

中文期刊一般喜欢“算例 + 实例”的双层验证结构。

算例分析用于说明：

- 模型在可控环境中是否收敛；
- 与基准策略相比是否有效；
- 评价指标是否合理。

实例分析用于说明：

- 方法在真实线路参数下是否仍有效；
- 实际数据如何处理；
- 结果是否具有工程解释。

刘月荣这篇建议：

- 环形线路作为算例分析；
- 成都 T34 路作为实例分析；
- 若篇幅有限，环形线路可压缩，T34 路作为主验证。

结果表述应遵循：

1. 先说明训练收敛性。
2. 再从车辆轨迹说明串车缓解。
3. 再从载客量或 AOD 说明资源利用均衡。
4. 最后用 AWT、AHT、ATT、AOD 表格给出量化结果。

结果段常用句式：

- “由图可见，在无控制策略下，车辆轨迹出现明显聚集，表明系统存在严重串车现象。”
- “与规则控制策略相比，强化学习策略能够根据实时状态动态调整驻站时间。”
- “所提方法在降低乘客等待时间的同时，减少了平均驻站时间，说明其并非通过增加控制干预换取车头时距稳定。”
- “与原始 MAPPO 相比，改进 MAPPO 在 AWT、AHT、ATT 和 AOD 指标上均取得更优结果，说明事件图注意力机制有助于提升异步决策场景下的协同控制能力。”

## 结论写法

中文期刊结论通常为 2-4 条编号式结论。

建议写法：

1. 建模结论：本文构建了面向公交串车防治的异步多智能体强化学习驻站控制模型。
2. 方法结论：通过事件图和图注意力机制增强 MAPPO 对相邻车辆异步到站事件的感知能力。
3. 实验结论：算例和实例结果表明，所提方法在 AWT、AHT、ATT、AOD 等指标上优于基准策略。
4. 局限与展望：后续可考虑多线路共线、车辆异质性、乘客放弃等待行为和实车在线验证。

## 语言风格

中文交通期刊常用“客观陈述 + 工程解释”的语言，不宜使用太多宣传性词汇。

推荐：

- “构建”
- “提出”
- “设计”
- “刻画”
- “表征”
- “验证”
- “结果表明”
- “与……相比”
- “在……指标上降低/提高”
- “具有一定工程应用潜力”

谨慎使用：

- “创新性地”
- “首次”
- “显著”
- “极大”
- “全面优于”
- “革命性”

如果使用“显著”，最好有统计检验或至少多次仿真均值和方差支持。

## 对刘月荣论文的改写取舍

必须保留：

- 公交串车问题和驻站控制需求
- 车辆运行系统模型
- 状态空间、动作空间、奖励函数
- 事件图和 GAT
- 改进 MAPPO 算法流程
- 环形线路算例
- 成都 T34 路实例
- 与 NH、HH、FH、BH、MAPPO 的对比
- AWT、AHT、ATT、AOD 结果表

必须压缩：

- 政策背景
- 强化学习基础理论
- 强化学习算法分类
- 国内外研究逐条综述
- 代码实现说明
- 大量重复车辆轨迹图

需要补强：

- 消融实验或至少明确说明“原始 MAPPO vs 改进 MAPPO”的差异来自事件图注意力机制。
- 多次仿真的均值、标准差或误差条。
- 数据来源、数据处理流程和可复现性说明。
- 结果中避免只说“表现更好”，要写清楚“在哪个指标、相对哪个基准、降低多少”。
